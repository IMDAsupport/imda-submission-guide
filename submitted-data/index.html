    Submitted Data

    Use Submitted Data to monitor submitted studies and curation progress.

    Tracking Your Study

    1. Review the table for Project ID, Study ID, Study Title, and Date of Submission.
    2. Open the Study ID or row details to view full metadata and current status.
    3. Use the final IMP_xxxxxx and IMS_xxxxxx accession identifiers for citation after release.
    Status Meaning Action Required
    Submitted Initial state awaiting review. None unless IMDA contacts you.
    In Curation Curator is reviewing metadata and data files. Check registered email frequently.
    Public Study is released for download. Cite the final accession identifiers.

    Processing Timeline

    The testing portal states that submissions are processed within 7 days, and submitters are notified by email.

    Corrections After Submission

    Use Edit File Data only when metadata or file corrections are required before final validation or during curator-requested correction.

    Submission Status Edit Button Status Required Action
    Pre-Submission Active Click the edit option for the relevant row.
    Post-Submission Disabled or hidden Contact IMDA support to request temporary edit access.

    Common edit actions include:

    • Edit Project / Study / Sample Details: Correct metadata before final validation.
    • Edit Upload Run: Replace corrupted or incorrect raw data files.
    • Edit Metabolite / Compound File: Replace the processed metabolite summary file.

    Edit Upload Run

    Use Edit Upload Run when a raw data file needs correction or replacement.

    Field What to Enter
    Study Select the study linked to the uploaded run.
    FTP Filename Select the uploaded file that needs correction.
    MD5 Checksum Enter the corrected lowercase checksum for the replacement file.

    Edit Metabolite / Compound File

    Use this option when the processed metabolite or compound file needs to be replaced.

    Field What to Enter
    Study Select the study linked to the processed file.
    Compound Document Upload the corrected metabolite or compound file.

    Controlled Vocabulary Updates

    Use Browse Lists to check whether an organism, source, or MS/NMR instrument term already exists. If the required term is missing, use Update List to submit a new controlled vocabulary request.

    Browse List What to Check
    MS Instrument Confirm whether the required mass spectrometry instrument already exists.
    NMR Instrument Confirm whether the required NMR instrument already exists.
    Source / Organism Terms Use existing controlled terms wherever possible.

    Update List

    Request a new master-list value only when the required value is not already available.

    Field What to Enter
    List Type Select the category to update, such as MS instrument, NMR instrument, organism, or source.
    Name / Value Enter the exact term to be added.

    Support and Citation

    Item Guidance
    Repository Indian Metabolome Data Archive (IMDA) of the Indian Biological Data Centre (IBDC).
    Project Accession Use the assigned IMP_xxxxxx identifier.
    Study Accession Use the assigned IMS_xxxxxx identifier.
    Support Email Contact imdasupport@ibdc.rcb.res.in for assistance.

    Common Mistakes

    Do not assume the submission is complete only because files were uploaded. Check the status in Submitted Data and respond quickly if IMDA requests corrections.
