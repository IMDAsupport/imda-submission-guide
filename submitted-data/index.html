    Submitted Data

    Use Submitted Data to monitor submitted studies and curation progress.

    MHD Alignment

    MHD Term IMDA SOP Meaning Minimum Expectation
    Study Submitted dataset record. Track status and accession identifiers.
    Repository Identifier IMDA/IBDC accession assigned to the record. Use assigned IMP_xxxxxx and IMS_xxxxxx identifiers for citation.
    Data Provider Person or organization responsible for the submission. Keep submitter, PI, and affiliation details accurate.
    Metadata File Stored metadata associated with the submission. Corrections should preserve consistency across project, study, sample, assay, and file records.

    Tracking Your Study

    1. Review the table for Project ID, Study ID, Study Title, and Date of Submission.
    2. Open the Study ID or row details to view full metadata and current status.
    3. Use the final IMP_xxxxxx and IMS_xxxxxx accession identifiers for citation after release.
    Status Meaning Action Required
    Submitted Initial state awaiting review. None unless IMDA contacts you.
    In Curation Curator is reviewing metadata and data files. Check registered email frequently.
    Public Study is released for download. Cite the final accession identifiers.

    Processing Timeline

    The testing portal states that submissions are processed within 7 days, and submitters are notified by email.

    Corrections After Submission

    Use Edit File Data only when metadata or file corrections are required before final validation or during curator-requested correction.

    Submission Status Edit Button Status Required Action
    Pre-Submission Active Click the edit option for the relevant row.
    Post-Submission Disabled or hidden Contact IMDA support to request temporary edit access.

    Common edit actions include:

    • Edit Project / Study / Sample Details: Correct metadata before final validation.
    • Edit Upload Run: Replace corrupted or incorrect raw data files.
    • Edit Metabolite / Compound File: Replace the processed metabolite summary file.

    Controlled Vocabulary Updates

    Use Browse Lists to check whether an organism, source, or MS/NMR instrument term already exists. If the required term is missing, use Update List to submit a new controlled vocabulary request.
