    Project

    Project registration establishes the high-level administrative umbrella for the data. A project can contain one or more related studies.

    Testing Portal

    Use the IMDA testing database for validation: https://ibdc.dbt.gov.in/imda_test/.

    Before You Start

    Complete these checks before beginning a new submission:

    • Prepare raw and derived data files.
    • Compress complex raw data folders into individual ZIP archives before transfer.
    • Use only letters, numbers, hyphens, underscores, and dots in file names.
    • Do not use spaces or special characters in file names.
    • Organize raw data into clear local folders before compression.
    • Install an FTP client such as FileZilla.
    • Use open formats where possible. IMDA prefers mzML for MS data and nmrML for NMR data.
    • Collect name, email, and affiliation details for the Principal Investigator and all contributing authors.
    • Prepare the study summary, keywords, DOI where applicable, and ethical or institutional approval numbers.

    Access

    Option User Action Purpose
    User Registration Open User Registration. Creates the account required for data submission.
    Login Open Login. Starts an authenticated session for submission and dashboard access.
    Submit Click Submit after login. Opens the new data submission workflow.

    Register Project

    Purpose: Define the overall research initiative, funding source, and investigators responsible for the data.

    What to Fill

    Field What to Enter Writing Guideline
    Title* Name of the overall research project, consortium, or data generation activity. Use one clear sentence or phrase.
    Project Contributors* Principal Investigator, submitter, and other responsible contributors. Enter full name, email, and institutional affiliation wherever requested.
    Research Area* Scientific domain of the project. Select the closest controlled term from the portal list.
    Funding Source* Grant agency, project number, institutional funding, or other support source. Use the official funder name and grant number if available.
    Project Description* Overall aim, biological context, and data type covered by the project. Keep it concise, usually 3-5 sentences.

    Final Action:

    1. Fill all fields marked with an asterisk.
    2. Check the funding source carefully.
    3. Click Submit to generate the project identifier.

    Project vs Study

    The Project defines the who and why. The Study defines the specific experiment.
