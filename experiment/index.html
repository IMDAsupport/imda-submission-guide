    Experiment

    Experiment registration tells IMDA how the samples were measured and which experiment/result files belong to the selected study.

    Experiment Form Screen

    Use Register Experiment from the left sidebar. Select the technique, select the correct study, upload the metabolite/compound file, and upload the completed MS or NMR experiment template.

    What to Fill in the Portal

    Portal Field What to Enter Writing Guideline
    Select Technique* Select the experiment technique, such as MS or NMR. Choose the same technique used in the study and template.
    Study Select the Study ID linked to this experiment. Make sure the selected study belongs to the correct project.
    Metabolite / Compound File Upload the raw, processed, or annotated metabolite/compound result file when available. Use a clear file name and keep the same name in later file mapping.
    MS/NMR File Template Upload the completed MS or NMR Excel template. Use MS template for mass spectrometry and NMR template for nuclear magnetic resonance. Do not change column headers.

    MS Template Columns

    Download the MS file template when the study uses mass spectrometry. Fill one row for each sample/file combination.

    MS Template Column What the User Should Fill
    Sample id IMDA-generated Sample ID from the Sample step. Copy it exactly.
    Sample Name Sample name used in the sample template.
    Reference Standard Reference standard or internal standard used. Enter NA if not applicable.
    Chromatography Instrument Name LC/GC/CE or other chromatography system used before MS.
    Column Model Chromatography column model/name.
    Column Type Column chemistry/type, such as C18, HILIC, GC column, or NA.
    Mass Spectrometer Type MS technique type, such as LCMS, GCMS, ICP-MS, or other available option.
    MS Instrument Name MS instrument model/name. Use the closest available option.
    MS Instrument Type Instrument type, such as QTOF, Triple TOF, ion trap, or other available option.
    MS Ionization Method Ionization source, such as ESI, APCI, APPI, MALDI, or other available option.
    Ion Mode/Scan Polarity Positive, negative, or both, as used during acquisition.
    Data Transformation(Software/s Used) Software used for conversion/processing, such as ProteoWizard, XCMS, MZmine, vendor software, or NA.
    MS Data File Name Exact raw/ZIP data file name that will be uploaded. Include the extension.
    Md5checksum MD5 checksum for the final uploaded MS data file. Generate it after the ZIP/file is final.

    NMR Template Columns

    Download the NMR file template when the study uses nuclear magnetic resonance. Fill one row for each sample/file combination.

    NMR Template Column What the User Should Fill
    Sample id IMDA-generated Sample ID from the Sample step. Copy it exactly.
    Sample Name Sample name used in the sample template.
    Reference Standard Reference standard used for NMR. Enter NA if not applicable.
    NMR Instrument Name NMR instrument model/name.
    NMR Type Solution NMR, solid-state NMR, or the closest available type.
    NMR Experiment Type Experiment type, such as 1D 1H, 1D 13C, 2D COSY, HSQC, or other available option.
    NMR Spectrometer Frequency Spectrometer frequency, such as 400 MHz, 500 MHz, or 600 MHz.
    NMR Probe Probe used for acquisition.
    NMR Probe Temperature Probe/sample temperature during acquisition, with unit where possible.
    NMR Solvent Solvent used, such as D2O, CDCl3, DMSO-d6, or other available option.
    NMR Tube Size Tube size, such as 5 mm, or NA if not applicable.
    Data Transformation(Software/s Used) Software used for processing/conversion.
    NMR Data File Name Exact raw/ZIP NMR data file name that will be uploaded. Include the extension.
    Md5checksum MD5 checksum for the final uploaded NMR data file. Generate it after the ZIP/file is final.

    Match IDs and File Names

    1. Use the Sample IDs generated in the Sample step.
    2. Use the correct template for the selected technique.
    3. Keep uploaded file names exactly the same as the file names entered in the template.
    4. Generate the MD5 checksum only after the final file or ZIP is ready.
    5. Use NA for required fields that are genuinely not applicable.

    Common Mistakes

    Do not use local sample names where IMDA expects Sample IDs. Do not rename template headers. Make sure technique, Study ID, file name, and MD5 checksum all match the final uploaded files.

    Final Action:

    1. Download the correct MS or NMR template.
    2. Fill the template using Sample IDs and exact file names.
    3. Calculate MD5 checksum for each final uploaded file.
    4. Upload the metabolite/compound file and the completed MS/NMR template.
    5. Click Submit.
